## 项目概述

本项目使用老师开发的**汉语言编程工具**（基于 Unity 的可视化编程环境，`.han` 格式源码）+ **Python（AlphaZero 算法）**，混合编程实现了一款海克斯棋（Hex）对弈系统，支持**人人对战**和**人机对战**。

### 海克斯棋规则

- 红蓝双方在 11×11 六边形棋盘上交替落子
- 红色方目标：连通上下边界（纵向）
- 蓝色方目标：连通左右边界（横向）
- 先连通对应边界的一方获胜

## 技术架构

### 汉语言部分（张欣宇）
- 使用汉语言编程工具实现棋盘 UI、棋子显示、鼠标交互
- 通过集合存储红/蓝/空三种棋子状态
- 深度优先搜索（DFS）实现胜利检测
- 全局变量控制玩家轮换

### Python AI 部分（张硕）
- 基于 **AlphaZero** 算法的强化学习框架
- 状态空间：11×11×(2n+1) 张量表示
- **蒙特卡洛树搜索（MCTS）** 进行决策
- **ResNet** 残差网络作为价值网络和策略网络
- 采用 PyTorch + Numba JIT 加速

### 教学测部分（姜滔）
- 教：海克斯棋起源、规则、策略、算法介绍
- 学：汉语言小程序使用演示
- 测：程序编写题目 + 人机对战体验

## 运行方式

### 汉语言程序
1. 进入 `汉语言编程-邢/` 目录
2. 运行 `ComInfo.exe`
3. 加载 `.han` 源文件即可运行

### Python AI
```bash
cd azalea_hex

# 安装依赖
pip install -e .

# 人机对战（使用预训练模型）
python play.py

# 训练模型
python train.py
```
